## Architecture Standard (All 204 Files)

### Naming Convention
```
{STEP-ID-lowercase-underscore}.dart
STEP-ID-A01  →  step_id_a01.dart
```

### File Structure (every file)
```dart
// Header: step ID · domain · atomic task · EC count · author
// EC EXECUTION LOGIC: verbatim EC lines

enum ExecutionStatus { pending, running, complete, failed }
enum StepOutcome { complete, partial, notComplete }

class {StepId}Entry        // Data model + 5 DCDF lineage fields
class {StepId}ScanResult   // Conformance gate result
class {StepId}Pipeline     // Static EC:1–N methods + validate + route
class {StepId}Widget       // Flutter ListView with PASS/FAIL chip
```

### DCDF Lineage Headers (all models, all 204 files)
```dart
final String traceId;
final String originSourceId;
final String immediatePredecessorId;
final String transformationLogicHash;
final bool   complianceStatusInd;
```

### Conformance Gate Pattern
```dart
bool get isConformant =>
    complianceStatusInd && executionStatus == ExecutionStatus.complete;
```

### Color Standard
- PASS: `Color(0xFF137333)` — Habot green
- FAIL: `Color(0xFFD93025)` — Habot red
