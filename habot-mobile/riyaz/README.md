## 1. Project Mission & Overview

**Application:** Habot Enterprise Mobile UI Component Library & Design System (Flutter 3.x / Dart 3.x).  
**Core Objective:** Implement, wire into `lib/main.dart`, and verify all atomic steps from the master operational checklist (`steps_backup.xlsx` / `audit_data.json`) in sequential batches.

* **Strict Quality Gate:** Zero Errors, Zero Warnings, Zero Hints enforced via `flutter analyze`.
* **Zero External Dependencies:** Built purely using standard Flutter & Material 3 components for complete isolation and fast execution.

## 2. Directory Hierarchy & Domain Decomposition

All step components reside as single, self-contained, isolated Dart files under `lib/core/<domain>/`.

```text
lib/
├── main.dart                                  # Step catalog registry & master UI launcher
└── core/                                      # Domain-driven architecture
    ├── accessibility/                         # WCAG contrast, minimum touch padding, semantics (24 components)
    ├── compliance/                            # Security gates, OPA rules, CI/CD verifiers (94 components)
    ├── interaction/                           # Tap handlers, gesture controls, hesitation trackers (48 components)
    ├── layout/                                # Responsive scaffolds, grid systems, viewports (49 components)
    ├── models/                                # StepItem model & StepCategory enum (2 components)
    ├── network/                               # BigQuery streamers, telemetry monitors (25 components)
    ├── theme/                                 # App tokens & Material 3 theme wrapper (3 components)
    ├── tokens/                                # Design tokens, typography scales, HSL palettes (51 components)
    ├── ui/                                    # UI widgets, cards, viewports, error boundaries (59 components)
    └── versioning/                            # Package version monitors, isolation panels (40 components)
```

### Domain Directory Breakdown

| Domain Directory | Component Count | Purpose & Usage |
|---|:---:|---|
| `lib/core/ui/` | 59 | Cards, empty states, modals, status chips, dashboards, viewports, visual indicators. |
| `lib/core/compliance/` | 94 | Security gates, OPA/Terraform rules, CI/CD checks, audit verifiers. |
| `lib/core/interaction/` | 48 | Tap handlers, gestures, voting buttons, hesitation trackers, focus listeners. |
| `lib/core/layout/` | 49 | Scaffolds, grid systems, adaptive split-screens, document auto-croppers, tab containers. |
| `lib/core/tokens/` | 51 | Design tokens, typography hierarchy, HSL palettes, spacing bounds, thumb zones. |
| `lib/core/network/` | 25 | Streamers (BigQuery), Pub/Sub handshakes, API perimeter filters, sync monitors. |
| `lib/core/accessibility/` | 24 | WCAG contrast, minimum touch target padding, screen reader semantics, keyboard insets. |
| `lib/core/versioning/` | 40 | Package version locking, context isolation, master data dictionaries. |
| `lib/core/models/` | 2 | StepItem models, StepCategory enums, domain data representations. |
| `lib/core/theme/` | 3 | M3 App Theme wrappers, color schemes, typography & visual token providers. |
