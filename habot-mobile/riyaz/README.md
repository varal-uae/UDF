## 1. Project Mission & Overview

**Application:** Habot Enterprise Mobile UI Component Library & Design System (Flutter 3.x / Dart 3.x).  
**Core Objective:** Implement, wire into `lib/main.dart`, and verify all atomic steps from the master operational checklist (`steps_backup.xlsx` / `audit_data.json`) in sequential batches.

* **Strict Quality Gate:** Zero Errors, Zero Warnings, Zero Hints enforced via `flutter analyze`.
* **Zero External Dependencies:** Built purely using standard Flutter & Material 3 components for complete isolation and fast execution.

## 2. Directory Hierarchy & Domain Decomposition

All step components reside as single, self-contained, isolated Dart files under `lib/core/<domain>/`.

```text
lib/
├── main.dart                                  # Step catalog registry & master UI launcher
└── core/                                      # Domain-driven architecture
    ├── accessibility/                         # WCAG contrast, minimum touch padding, semantics (10 components)
    ├── compliance/                            # Security gates, OPA rules, CI/CD verifiers (40 components)
    ├── interaction/                           # Tap handlers, gesture controls, hesitation trackers (21 components)
    ├── layout/                                # Responsive scaffolds, grid systems, viewports (18 components)
    ├── models/                                # StepItem model & StepCategory enum (1 components)
    ├── network/                               # BigQuery streamers, telemetry monitors (14 components)
    ├── theme/                                 # App tokens & Material 3 theme wrapper (3 components)
    ├── tokens/                                # Design tokens, typography scales, HSL palettes (20 components)
    ├── ui/                                    # UI widgets, cards, viewports, error boundaries (26 components)
    └── versioning/                            # Package version monitors, isolation panels (11 components)
```

### Domain Directory Breakdown

| Domain Directory | Component Count | Purpose & Usage |
|---|:---:|---|
| `lib/core/ui/` | 26 | Cards, empty states, modals, status chips, dashboards, viewports, visual indicators. |
| `lib/core/compliance/` | 40 | Security gates, OPA/Terraform rules, CI/CD checks, audit verifiers. |
| `lib/core/interaction/` | 21 | Tap handlers, gestures, voting buttons, hesitation trackers, focus listeners. |
| `lib/core/layout/` | 18 | Scaffolds, grid systems, adaptive split-screens, document auto-croppers, tab containers. |
| `lib/core/tokens/` | 20 | Design tokens, typography hierarchy, HSL palettes, spacing bounds, thumb zones. |
| `lib/core/network/` | 14 | Streamers (BigQuery), Pub/Sub handshakes, API perimeter filters, sync monitors. |
| `lib/core/accessibility/` | 10 | WCAG contrast, minimum touch target padding, screen reader semantics, keyboard insets. |
| `lib/core/versioning/` | 11 | Package version locking, context isolation, master data dictionaries. |
| `lib/core/models/` | 1 | StepItem models, StepCategory enums, domain data representations. |
| `lib/core/theme/` | 3 | M3 App Theme wrappers, color schemes, typography & visual token providers. |
