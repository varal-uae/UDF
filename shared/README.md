# shared

The Habot design system and shared assets used across UDF projects — the **source of truth** for colors, spacing, typography, and reusable components.

> Placeholder — populate as the design system takes shape.

## What belongs here

- **Design tokens** — colors, spacing scale, typography
- **Shared components** — cross-project UI building blocks
- **Assets** — logos, icons, fonts

## Usage

`habot-web` and `habot-mobile` consume these tokens rather than hardcoding values. Change a token here, and both surfaces stay in sync.
